reed-hunt-input

The input field nobody asked for

Digits fly up out of the reeds. Shoot one and it lands in the next slot. The red cross erases the last digit. You get 20% more ammo than you need. Run out and the free ammo is over, but for just €1 …

value: ""

Install

npm i reed-hunt-input

React

import { ReedHuntInput, reedHuntFormats } from 'reed-hunt-input/react';

const [card, setCard] = useState('');

<ReedHuntInput
  format={reedHuntFormats.card}
  value={card}
  onValueChange={setCard}
/>

Vue

import { ReedHuntInput, reedHuntFormats } from 'reed-hunt-input/vue';

<ReedHuntInput
  v-model="pin"
  :format="reedHuntFormats.pin"
  @complete="unlock"
/>

Plain JS

import { createReedHunt, reedHuntFormats } from 'reed-hunt-input';

createReedHunt(document.querySelector('#amount'), {
  format: reedHuntFormats.amount,
  onChange: (digits) => console.log(digits),
});
